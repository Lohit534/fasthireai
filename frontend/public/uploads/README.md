# Public Uploads Directory

Place your demo video and static media files in this folder.

### Demo Video Usage:
- Recommended file name: `demo.mp4` (or `demo.webm`, `demo.mov`)
- File location: `frontend/public/uploads/demo.mp4`
- Public URL: `http://localhost:3000/uploads/demo.mp4`

When visitors click **"See Demo"** or **"Watch Demo"** on the website, this video will play inside the interactive video player modal.
